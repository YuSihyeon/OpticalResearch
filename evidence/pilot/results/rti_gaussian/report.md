# RTI-Gaussian Pilot Report

## Summary

This run compares fixed-color, Lambertian, and polynomial RTI 2D Gaussian attributes on train lights and held-out light reconstruction.

## Metrics

Fixed held-out MAE: 0.0290. Lambertian held-out MAE: 0.0362. RTI held-out MAE: 0.0263.

## Limitations

This is a 2D image-plane pilot. It tests light-response attributes, not 3D visibility, camera projection, or full 3DGS rendering.
