## Page 1
RGB-only 3D Relighting 과 
Spectral Metamerism 중간 점검 정리 
 
대표 시각화: D65 에서는 비슷해 보이지만, 조명 변화 후 GT 와 모델 prediction 의 관계가 달라진다. 
1. 연구 배경: 왜 RGB-only relighting 에서 메타머리즘이 문제가 되는가? 
일반적인 RGB 카메라는 장면을 빨강, 초록, 파랑 세 채널로만 기록한다. 하지만 실제 재질은 파장별로 빛을 얼마나 
반사하는지가 모두 다르다. 이 파장별 반사 정보를 반사 스펙트럼이라고 부른다. 
문제는 서로 다른 반사 스펙트럼을 가진 두 재질이 특정 조명 아래에서는 같은 RGB 로 보일 수 있다는 점이다. 이런 
현상을 메타머리즘이라고 한다. 즉, 카메라에는 같은 색으로 보이지만 실제 물리적 원인은 다른 경우다. 
 
따라서 RGB-only 3D relighting 모델이 새로운 조명에서 정확한 색을 예측하려면, RGB 이미지에는 기록되지 않은 
스펙트럼 정보를 암묵적으로 추정해야 하는 문제가 생긴다. 이 정보가 실제로 추정 가능한지, 아니면 원리적으로 
모호한지 확인하는 것이 이번 연구의 출발점이다.

여기서 World A 와 World B 는 기하 구조, 카메라 위치, 노출, 장면 구조는 같고 재질의 반사 스펙트럼만 다르게 만든 
두 세계다.  
3. 실험을 설계한 사고 과정 
1. 먼저 실제 스펙트럼이 다른 두 재질 세계 A/B 를 만든다. 
2. D65 조명과 Nikon D5100 카메라 응답을 적용했을 때 두 세계가 같은 RGB 로 보이도록 맞춘다. 
3. Mitsuba 3 spectral renderer 로 조명을 바꿨을 때의 기준 정답 GT 를 만든다. 
4. R3DG 와 GS-IR 에는 D65 RGB 만 학습시키고, 이후 조명 proxy 를 넣어 relighting 결과를 만든다. 
5. GT 와 모델 prediction 사이의 관계를 비교한다. 
 
실험 사고 과정: 스펙트럼이 다른 두 세계 → D65 에서는 같은 RGB → 조명 변화 후 GT 와 모델 결과 비교

6. 실험 2 실제 모델 출력 구조 
현재 구조에서 실제 모델인 R3DG 와 GS-IR 은 World A 용 출력과 World B 용 출력을 따로 만들지 않는다. 둘 다 같은 
D65 RGB 관측을 보고 각자 하나의 공통 prediction 을 만든다. 
실제 구조 
같은 RGB → R3DG prediction 하나 
같은 RGB → GS-IR prediction 하나 
 
 
실제 장면 기록: LED-RGB1 에서 R3DG common prediction 과 GS-IR common prediction. 두 모델은 같은 RGB 에서 출발했지만 서로 다른 
appearance 를 만든다. 
7. R3DG 와 GS-IR 의 결과가 왜 다른가? 
R3DG 와 GS-IR 은 같은 D65 RGB 정보를 사용했지만, 새 조명에서 만든 prediction 은 서로 같지 않다.  
가장 쉬운 이유는 두 방법이 RGB 사진에서 장면의 물리적 원인을 추정하는 방식이 다르기 때문이다. RGB 사진 
하나에는 색만 보이지만, 그 색이 생긴 원인은 여러 가지일 수 있다. 재질이 밝아서 밝게 보인 것일 수도 있고, 조명이 
강해서 밝게 보인 것일 수도 있고, 표면 방향이나 그림자 때문일 수도 있다. 
• R3DG 와 GS-IR 은 모두 RGB 이미지를 보고 geometry, material, lighting, visibility 같은 요소를 나누어 추정하려고 
한다. 
• 하지만 이 분해는 RGB 만으로 유일하게 정해지지 않는다. 
• 따라서 같은 D65 RGB 를 보고도 두 방법은 서로 다른 내부 설명을 만들 수 있다. 
• 새 조명을 적용하면 그 내부 설명의 차이가 prediction 차이로 드러난다.
